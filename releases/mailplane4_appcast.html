Mailplane 4 and macOS 27

We tested Mailplane 4.3.15 on macOS 27, and it continues to work in our testing. On Apple silicon Macs, Mailplane 4 requires Rosetta. macOS will offer to install it automatically if needed, and the installation takes only a few seconds. The system warning shown by macOS 27 refers to macOS 28, the next major release—not macOS 27.

Meanwhile, we're busy giving Mailplane a new engine. Mailplane 5 for Apple silicon and Intel Macs is in development. Read more.
